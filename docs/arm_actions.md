# Arm Actions Protocol V1

本文档用于规定Rosclaw-Mini 当前支持的机械臂技能、命令格式、参数要求和安全限制。

当前协议用于 MockArm 模拟阶段。接入真实机械臂后，坐标系、单位和安全范围需要根据真实驱动重新确定。

## 通用命令格式

所有命令采用以下 JSON 格式，包含以下字段：
```
{
  "skill_name": "string", // 命令名称
  "params": {}          // 命令参数
}
```

### LLM 输出字段

| 字段 | 类型 | 是否必需 | 含义 |
| --- | --- | --- | --- |
| skill_name | string | 是 | 命令名称，必须为支持的技能名称 |
| params | object | 是 | 命令参数，必须为技能所需的参数


### 系统生成字段

LLM不需要生成以下字段，系统会在接收到 LLM 输出后自动添加：
| 字段 | 生成者 | 含义 |
| --- | --- | --- |
| command_id | 系统 | 命令ID，用于唯一标识每个命令 |
| source | 系统 | 命令来源，固定为 "llm" |


## 支持的技能列表

| 技能名称 | 功能 | 风险等级 |
| --- | --- | --- |
| move_arm | 移动机械臂到指定位置 | 中 |
| pick | 抓取物体 | 高 |
| open_gripper | 打开机械爪 | 低 |
| close_gripper | 关闭机械爪 | 低 |
| stop | 停止当前动作 | 中 |

不在技能列表中的命令目前将被视为无效命令，系统会返回错误信息。

## move_arm 技能

### 功能
将机械臂移动到指定的目标位置。
当前‘move_arm’技能仅表示目标位置，不表示相对移动。机械臂将直接移动到指定的绝对位置。

### 参数要求
| 参数名称 | 类型 | 是否必需 | 含义 | 范围 |
| --- | --- | --- | --- | --- |
| x | float | 是 | 目标位置的 X 坐标 | -1.0 ~ 1.0 |
| y | float | 是 | 目标位置的 Y 坐标 | -1.0 ~ 1.0 |
| z | float | 是 | 目标位置的 Z �坐标 | 0.0 ~ 1.0 |
| roll | float | 否 | 目标位置的滚转角度（绕 X 轴旋转） | -180

### 单位说明
当前处于 MockArm 模拟阶段，坐标单位为米，角度单位为度。接入真实机械臂后，坐标系、单位和安全范围需要根据真实驱动重新确定：
- 坐标系：机械臂的坐标系为右手坐标系，原点位于机械臂基座中心。
- 单位：坐标单位为米，角度单位为度。
- 实际安全范围：机械臂的实际运动范围和安全限制需要根据真实机械臂的规格和驱动进行调整。

### 正确示例
```json
{
  "skill_name": "move_arm",
  "params": {
    "x": 0.5,
    "y": 0.2,
    "z": 0.3,
    "roll": 45
  }
}
```

### 错误示例
```json
{
  "skill_name": "move_arm",
  "params": {
    "x": 1.5, // 超出范围
    "y": 0.2,
    "z": 0.3,
    "roll": 45
  }
}
```

```
{
  "skill_name": "move_arm",
  "params": {
    "x": 0.5,
    "y": 0.2
    // 缺少 z 参数
  }
}
```

### 风险等级
medium
