# SO-100 Plus 不规则工作空间限制

## 当前运行时范围

当前 `right_follower` 的 `move_arm` 和 `move_relative` 已使用
`middle_internal` 固定 TCP 朝向的 1 cm 不规则扫描网格，不再把工作空间
简化成一个大长方体。

正式加载的快照为：

```text
artifacts/so100_plus_middle_workspace_10mm_final/rest_workspace_grid.npz
SHA-256: c139f4e9f75343d01a368fea30dfc3d1b1d40ae13dfbc7f9f84e14f2bb34ad27
```

运行时允许两类目标：

1. 扫描保存的全部 `10,974` 个有效网格节点；
2. 一个连续网格单元的所有必要角点均有效时，该单元的边、面和内部。

当前共有 `9,044` 个八角全部有效的连续 1 cm 单元。AABB 内某个单元只要
存在无效必要角点就会被拒绝，程序不会用最近节点吸附命令，也不会跨过
点集中的空洞。

有效节点投影到三个坐标轴的独立极值为：

```text
X:  0.173571 .. 0.523571 m
Y: -0.161185 .. 0.098815 m
Z:  0.039328 .. 0.379328 m
```

这些数值只供 Gateway 快速粗筛，不能交叉组合成安全长方体。最终放行由
`SO100PlusIrregularWorkspace.validate_position()` 完成。

## 运动通道

扫描证明的是 `middle_internal → 每个有效节点` 的固定朝向关节通道，
不是任意两个有效点之间的直达路径。因此普通工作动作采用保守中心通道：

```text
当前实际 WORK 姿态
→ middle_internal
→ 用户目标
```

对于精确网格节点，第二段使用扫描产物保存的六关节解；对于八角全部有效
单元内的连续目标，从 `middle_internal` 保持同一 TCP 朝向重新求解 IK。
两段最终 30 Hz waypoint 会在运动前一次性固化，并共同经过：

- 关节及实测底座范围；
- 实际夹爪 qpos；
- MuJoCo 全 waypoint 接触/碰撞检查；
- TCP 不低于桌面；
- stop、跟踪误差、负载、温度和最终到位保护。

MuJoCo 通过的 `JointMotionPlan` 会原样交给 Adapter，执行阶段不会重新
插值或规划。任何预检查失败都发生在第一条电机目标之前。

## 配置绑定与失败关闭

统一真机运行时会在创建 Robot 前完成：

1. `/dev/lerobot_right`、`right` follower 和校准文件 SHA-256 绑定；
2. 不规则 NPZ 文件存在性、固定 SHA-256 和必要字段校验；
3. `middle_internal` 参考 TCP、六关节、1 cm 步长、10,974 点和
   `-5°/60°` 夹爪交集校验；
4. 所有有效点关节解、模型关节范围和实测底座范围校验；
5. MuJoCo 模型可用性检查。

任一项失败时，在创建或连接 Robot 前拒绝启动。工作 Adapter 内部使用的
轴对齐范围只是数值规划外包框；用户命令必须经过会话层不规则网格门禁，
不能直接利用该外包框绕过空洞检查。

## 相对运动

`move_relative(dx, dy, dz)` 在动作真正开始时读取实际 TCP，再计算最终
绝对目标。最终目标必须属于上述不规则节点或完整有效单元，然后与
`move_arm` 共用中心通道和完整轨迹预检。

真实到位 TCP 如果恰好因已有 `12 mm` 到位容差落在离散边界外，程序不会
扩大可命令目标空间；只有它仍在计划目标的既有到位容差内、六关节和底座
合法、实际夹爪可映射且 MuJoCo 静态姿态无接触时，才继续保持 `WORK`。

## 适用条件与认证等级

不规则空间只适用于当前 `right_follower`、当前校准哈希、底座、TCP
定义、MuJoCo 模型、桌面 `Z=0`、固定 `middle_internal` TCP 朝向以及无
新增障碍物的工位。

它是“仿真扫描 + 运行时逐轨迹预检”的候选扩展，不代表 10,974 个节点都
已完成真机验收。首次实际使用应由操作者在场，从靠近旧核心的少量点开始，
逐步检查边界、线缆、负载、温度和实际到位误差。更换机械臂、校准、工具、
底座、模型或工位后必须重新扫描和认证。
